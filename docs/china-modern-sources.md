# 中国近现代政治思潮公开学术源侦察（政心任务 1.5）

日期：2026-10-23。执行环境：本地开发机（macOS），只读侦察。目标：为政心参照系中国线（design.md D2：近现代思潮优先 + 先秦 curated 种子谱系）定位可摄取的公开学术源，并对先秦诸子种子谱系来源给出定案建议。

结论先行：**五思潮全部定位到可摄取公开源，无整线缺口**。主通道意外地集中在 Wikimedia 基础设施上：维基文库（zh.wikisource.org，论战文献全文，本机直连可用）+ 维基共享（commons.wikimedia.org，国图 NLC 原刊扫描 PDF，本机直连可用）。真正的缺口是期刊原刊级的完整性（新青年/民報合订本）、新儒家早期部分人物（熊十力）、以及 1920-30 年代社会主义论战非主线人物（张东荪专文）。

## 通用许可注意（Wikimedia 两通道）

- **维基文库文本**：底本为公版文献（PD-China 等），维基文库的编辑版本按 CC BY-SA 4.0 发布。摄取入库可行，落库时带源条目 URL 与「维基文库编辑版 CC BY-SA 4.0」署名字段（照哲思许可门纪律）。
- **Commons 国图扫描 PDF**：文件页标注 Public domain、Credit 为 National Library of China（国图民国文献数字化释放，如 NLC404/NLC511 编号系列）。美国法项下判定 PD；**中国法项下注意**：作者逝世后 50 年保护期以单篇作者计（如学衡主将吴宓卒于 1978，单篇文字权至 2028）。政心 v1 对期刊扫描的用法建议：整刊作「源文档锚点」链接 + 目录级索引（期号/篇名/作者），选篇 OCR 全文须限量并二次人工校对，不做整刊批量 OCR 入库。此结论并入 data-license.md 台账（任务 1.1/1.2 同文档）。

## 先秦诸子种子谱系来源定案

政心设计约束（design.md D2/D3）：先秦诸子以 **curated 种子谱系**呈现——种子是谱系坐标不是语料，种子不造数值坐标。候选源对比（本机实测）：

| 候选 | 本机实测 | 作骨架（人物/学派/师承批判） | 作原典锚点 | 评价 |
| --- | --- | --- | --- | --- |
| ctext.org | 403（robot）；API 需 key | 弱：以文本为中心，无结构化人物关系 | 最权威（先秦两汉原典 canon，篇目级 URL） | 不作摄取对象、只链不抄 |
| 中文维基百科 | 本机不通（需生产代理） | **强**：人物×学派条目成体系、师承/论敌/影响叙述密度高、CC BY-SA 可衍生加工 | 一般（条目附原典链接） | **curating 底稿主源** |
| Wikidata | 本机不通 | 弱-中：P1066/P737 等关系边在先秦面稀疏，批判关系无标准属性 | 无 | 只作 QID 对齐（CC0，复用任务 1.3 SPARQL 通道） |
| 维基文库 | **直连可用** | 弱：无结构化元数据 | **强**：論語/孟子/荀子/墨子/韓非子/莊子/老子/商君書/管子/呂氏春秋 全部 200，公版全文 | 概念原文支撑层 |

**定案建议（三层分工，单一主源定为中文维基百科条目群）：**

1. **谱系骨架**：以中文维基百科条目群为 curating 底稿（人物条目 × 学派条目 × 概念条目交叉核对）。入库的是编辑产出的种子 JSON（人物/学派/概念/关系边，每条带来源 URL 与核对日期），**不是百科语料本身**——许可上 CC BY-SA 4.0 署名可溯源，内容上是人工提炼，符合「种子是坐标不是语料」。
2. **标识符对齐**：每种子挂 Wikidata QID（CC0），复用 D2 已规划的 SPARQL 通道（任务 1.3 实测时顺带核先秦诸子 QID）。Wikidata 不作骨架：先秦关系边稀疏且无「批判」标准属性，骨架靠人工 curate 更可靠。
3. **原典锚点**：每概念/人物的核心文本篇目引用 ctext.org 篇目 URL（规范引用，只链不抄——本机 403 与 API key 壁垒不构成阻碍，因为只存 URL 不抓内容）；需要原文佐证概念定义时，摄取维基文库同典文本（公版、本机直连、与近现代文献层同一基础设施）。

**粒度（v1 建议上限，宁粗勿细）：**

- 学派 6–8 家：儒、墨、道、法、名、阴阳为主，农/杂按需（有独立政治概念才立）。
- 人物 30–40 人：孔孟荀、老庄、杨朱、墨子及后期墨家代表、商鞅、申不害、慎到、韩非、李斯、惠施、公孙龙、邹衍、许行、吕不韦、管仲（托名层单列标注）等；不含稷下学宫逐人、儒家八派细分（二期按需扩）。
- 核心政治概念 40–60 个：仁政、王道、霸道、礼治、德治、无为、法治、势、术、兼爱、尚同、非攻、正名、大同、小康、民本、尊君、封建/郡县之辨等；每概念双锚（ctext 篇目 + 百科条目）。
- 师承/批判关系边 80–120 条：师承型（孔—曾—孟、荀—韩非/李斯）与批判型（孟子辟杨墨、庄子《天下》评百家、韩非《显学》驳儒墨、荀子《非十二子》）并立，边带出典篇目。

**为什么粗粒度**：(a) 任务 2.5 只要求谱系链「每环带人物/流派/年代/来源」，种子是定位坐标，粗粒度即可满足定位闭环；(b) curated 种子的风险在人工错误而非覆盖不足，粒度越粗单条核对成本越低、越符合「宁缺毋滥」；(c) 关系边出典到篇目即可回溯，不依赖数值坐标（D3 纪律）。

## 整体缺口结论

1. **五思潮无整线缺口**，且通道收敛：全文层全在维基文库（本机直连可开发），扫描层全在 Commons（国图 NLC 系列，PD 标注）。中国近现代政治思想史「无 SEP 等价物」属实，但 Wikimedia 通道的实际覆盖显著好于 design.md 风险预估。
2. **真实缺口（v1 诚实标注项）**：
   - 期刊原刊级完整性：《新青年》《民報》合订本公开扫描未在 Commons 定位到（维基文库仅散篇+期刊汇集页，期号完整性不保证；archive.org 本机不通未能排查，生产代理下可补一轮）；
   - 新儒家早期：除梁漱溟（有 NLC 扫描）外，熊十力《新唯识论》等未见公开可摄取版（Commons 0 命中，作者卒年 1968，扫描/文本两层的公开可得性都差）；吴宓/梅光迪文集无公开电子版；
   - 社会主义论战非主线人物专文：张东荪《现在与将来》等未见独立条目（其论战参与已由《关于社会主义的讨论》合集部分覆盖）；
   - ctext.org 不可抓取（403+API key），先秦原典**全文摄取**若超维基文库覆盖范围时是通道缺口（v1 定案已绕开：维基文库十部核心子书全在）。
3. **对任务 2.5 的落地建议**：近现代思潮文献层以维基文库散篇+作者页为主干；学衡派以 Commons 79 期扫描做目录级索引+选篇 OCR；先秦种子按本定案三层分工执行；中文维基百科/维基数据的抓取统一走生产代理通道（与任务 1.3 同通道），本机侦察结果可直接作为源清单输入。

## 复现要点（curl，UA=Chrome）

- 维基文库条目：`curl -sL "https://zh.wikisource.org/wiki/<条目>"`（标题用繁体原名）
- 维基文库全文检索：`https://zh.wikisource.org/w/api.php?action=query&list=search&srsearch=<词>`
- Commons 分类列举：`https://commons.wikimedia.org/w/api.php?action=query&list=categorymembers&cmtitle=Category:學衡`
- Commons 文件许可：`…&titles=File:<名>&prop=imageinfo&iiprop=size|extmetadata`
