# 政心参照系 · 数据许可前置核验（V-Dem / MARPOR）

核验日期：2026-10-23
核验方式：官网一手页面抓取（WebFetch / webReader 直抓）+ 直链 HTTP 实测（curl）；所有引文为官网英文原文逐字引用，未经转述改写。传闻「V-Dem 近年为 CC BY 4.0」经官网核实**不成立**：官网两处原文均为 **CC BY-SA 4.0**（多出 ShareAlike 条件）。

---

## 1. V-Dem（Varieties of Democracy，政体指标）

### 许可结论（三选一）

**需署名**（CC BY-SA 4.0：允许使用/改编/再分发，含商业用途；条件为署名 + 衍生作品以同许可传播）。

### 许可原文关键句引用

官网 FAQ（https://www.v-dem.net/about/faq，2026 版，© Copyright 2026）：

> "The V-Dem Dataset is publicly available and published under a Creative Commons Attribution-ShareAlike (CC BY-SA) 4.0 license. This means that anyone is free to use, adapt, and share the data, including for commercial purposes, provided that appropriate attribution is given and that any derivative products are distributed under the same license terms."

官网 FAQ 建议引用格式（原文）：

> Coppedge, Michael / Edelson, John / Golder, Sona N. / … / Tzelgov, Eitan and Wang, Yi-ting. 2026. "V-Dem [Country-Year/Country-Date] Dataset v16" Varieties of Democracy (V-Dem) Project. https://doi.org/10.23696/vdemds26

注意：官网页脚另有 "© Copyright 2026 Varieties of Democracy. All Rights Reserved."（整站版权），数据集本身的许可以上述 CC BY-SA 4.0 声明为准（FAQ 与数据页两处一致）。

### 出处 URL

- 许可声明（FAQ）：https://www.v-dem.net/about/faq
- 许可声明（数据集页）：https://www.v-dem.net/data/the-v-dem-dataset
- v16 发布说明：https://www.v-dem.net/release-statement-for-v16-of-the-v-dem-dataset
- 佐证（GitHub 官方账号）：https://github.com/vdeminstitute/vdemdata/releases

### 获取通道

- 官方下载页（当前版本 v16，2026-03 发布）：https://www.v-dem.net/data/the-v-dem-dataset
  - 四个变体各有子页（如 Country-Year: V-Dem Core v16 → https://www.v-dem.net/data/the-v-dem-dataset/country-year-v-dem-core-v16 ；Full+Others、Country-Date、Coder-Level 类似）。
  - **无需注册账号**，但子页为表单式下载（官方子页实测原文字段）：Email*、Gender*、Newsletter 勾选（"Add my email to our mailing list…"）、隐私同意*（"I approve the processing of personal data in accordance with the V-Dem privacy policy"）、格式选择*（STATA / CSV / R / SPSS）；提交后 "Your download should start automatically, if not you can start the download manually."
  - 每个快照 ZIP 内含：Dataset、Codebook、What's New、Cautionary Notes、**Suggested Citations**（署名文件随快照走，正好满足入库留证）。
- 历史版本存档（快照版本化用）：https://www.v-dem.net/data/dataset-archive
- 备选通道（官网 FAQ 列出）：R 包 `vdemdata`（GitHub: vdeminstitute/vdemdata）、DEMSCORE e-infrastructure。

### 对拟议用途（参照系入库 + 快照版本化 + 保留归属声明 + 产品查询面）的合规结论

**合规可行（需署名）**，附两个注意点：

1. **入库快照 + 版本化**：允许。建议随每个版本快照原样保留 ZIP 内的 Suggested Citations / Codebook 等归属文件。
2. **保留归属声明 + 产品查询面**：允许（含商业产品），必须按 CC BY-SA 4.0 给署名（推荐引用格式 + DOI + 许可链接 + 变更说明）。
3. **ShareAlike 触发边界**：仅内部存储与查询展示不构成「分发」；但若产品允许最终用户**导出/下载** V-Dem 数据或其改编数据集，则属分发衍生作品，须以 CC BY-SA 4.0 同许可提供并附署名。
4. **第三方列污染**：「Country-Year: V-Dem Full+Others」变体捆绑 "other indicators from other sources"（第三方指标），不受 V-Dem 的 CC BY-SA 声明覆盖。建议摄取 **Core** 或 **Country-Date** 纯 V-Dem 变体；若用 Full+Others，须对第三方列单独核验许可。

## 2. MARPOR（Manifesto Project，政党纲领编码）

### 许可结论（三选一）

**需署名**（无 CC 类公共许可；自定义 Terms of Use：强制引用 + 数据再分发默认禁止、须书面授权；数据以科研用途为提供目的）。

### 许可原文关键句引用

官网 Terms of Use（https://manifestoproject.wzb.eu/information/documents/terms_of_use，全文实测抓取）：

> "The Manifesto Project provides data generated by or collected for the Manifesto Project for the purposes of scientific research."

> "You agree to reference the recommended bibliographic citation in any publication (books, articles, conference papers, theses, dissertations, working papers, etc.) that employs the provided resource."

> "**Redistribution of the provided data is forbidden** except when redistribution is authorized in writing by the Manifesto Project. To be sure that the terms of use are not violated, redistributed data needs to be stored in a way that allows you to identify their provenance (the Manifesto Project Data Collection) — the approved redistribution has to include all files provided with the data set (e.g. the terms of use)."

> "By using the data or documents, or by downloading data or documents from this website, you agree to these terms and conditions."

官网数据集页（MPDS2026a）推荐引用（原文）：

> Lehmann, Pola / Franzmann, Simon / Al-Gaddooa, Denise / Ivanusch, Christoph / Riethmüller, Felicia / Samstag, Svenja / Volkens, Andrea / Weßels, Bernhard / Zehnter, Lisa (2026): "The Manifesto Data Collection. Manifesto Project (MRG/CMP/MARPOR). Version 2026a." Berlin: WZB / Göttingen: IfDem. https://doi.org/10.25522/manifesto.mpds.2026a

### 出处 URL

- Terms of Use（许可原文）：https://manifestoproject.wzb.eu/information/documents/terms_of_use
- 当前版本数据页（MPDS2026a，含引用文件 txt/bib/ris）：https://manifestoproject.wzb.eu/datasets/MPDS2026a
- 数据集总入口：https://manifestoproject.wzb.eu/datasets

### 获取通道

- 入口：https://manifestoproject.wzb.eu/datasets → 版本页（当前 MPDS2026a），提供 Stata 13 / Stata 14 / SPSS / CSV / XLSX 五种格式按钮；Codebook、Release notes、Coded documents list、Party lists、引用文件（txt/bib/ris）同页。
- **主数据集文件直链：未确认**。实测：版本页静态 HTML 中数据文件按钮均为 `#` 占位（JS 动态触发）；直链探测 `https://manifestoproject.wzb.eu/down/data/2026a/datasets/MPDataset_MPDS2026a_stata.zip`（及 stata14/spss/xlsx/csv 变体）均 302 → `https://manifestoproject.wzb.eu/information/error`（404）。同站文档类文件 `/down/data/2026a/codebooks/…` 可匿名直下（HTTP 200 实测通过）。站点导航有 LOGIN/SIGNUP。→ 初步判断主数据集下载很可能需免费注册登录，但**未经浏览器人工实测确认**。
- API 与 manifestoR R 包通道存在但需 API key（站点页面提及，未逐一实测）。

### 对拟议用途（参照系入库 + 快照版本化 + 保留归属声明 + 产品查询面）的合规结论

**部分合规、部分未确认**：

1. **入库快照 + 版本化**：可行且有条款依据——Terms of Use 本身要求"以可识别来源的方式存储数据、并在相应文件夹保留 terms of use 文件"，与快照+归属文件随行设计一致；前提是用途可归入 "purposes of scientific research"（见未确认点 2）。
2. **保留归属声明**：条款强制要求（引用 MPDS2026a 推荐格式 + DOI），照做即可。
3. **产品查询面**：内部查询属"使用"，配署名可行；但**向最终用户返回/导出 MARPOR 原始数据（批量数据面、下载接口）很可能构成 Redistribution**——条款原文"forbidden except when… authorized in writing"，即默认禁止、须 WZB 书面授权后方可放行。
4. 义务项：任何公开发表须引用推荐文献格式，并需向 Manifesto Project 回送发表引用（publications database）。

### 未确认清单（需人工跟进，不得臆断）

1. **主数据集下载是否强制注册登录**：需在浏览器人工走一遍下载流程确认（静态按钮为 `#`，直链 404）。
2. **「政心」产品语境是否满足 "purposes of scientific research"**：Terms of Use 以科研为提供目的，商业产品定位是否被接受无明文，需邮件确认：manifesto-communication@wzb.eu（官网提供的联系邮箱）。
3. **产品查询面是否被视为 Redistribution**：尤其若产品提供数据导出/下载功能；需向 Manifesto Project 申请书面授权（条款允许书面授权后再分发）。
